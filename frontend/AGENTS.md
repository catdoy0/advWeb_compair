# AGENTS.md: guide for AI agents

Write readable and simple code, avoid writing complex short code snippets just because its the standard and more efficient, we value readability more. Use clear variable names, Break down complex logic into smaller functions to improve readability. Avoid using obscure libraries or functions that may confuse readers.

Coding style should be consistent throughout the codebase. Use comments to explain important sections of code. Avoid using magic numbers; instead, define constants with descriptive names.

Use an early return pattern to reduce nested code and improve readability. Use error handling to manage exceptions gracefully and provide meaningful error messages.

Avoid chaining too many methods together in a single line, as it can reduce readability. Instead, break them into multiple lines for clarity.

When writing functions, ensure they have a single responsibility and are not too long. If a function is doing too much, consider breaking it down into smaller helper functions.

Never crash the program without handling exceptions. Always validate inputs and handle edge cases to prevent unexpected behavior.

When working with data structures, choose the most appropriate one for the task at hand. Use lists, dictionaries, sets, and tuples appropriately based on their characteristics and performance.
